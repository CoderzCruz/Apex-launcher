# Apex Launcher 2.0.0 — the Diwali launch

Apex Launcher 2.0 is here. This is the big one the countdown page has been promising: the
assistant, the new look, and the social layer, all in a single public release.

## Highlights

- **Apex Service** — an AI assistant pinned at the top of Chats. It answers with a live Gemini
  model when an AI key is configured, falls back to an honest built-in knowledge base when it is
  not, ships starter prompts, breathing typing dots and a New chat reset, and mentions work inside
  shared rooms with `@apex`.
- **A brand-new look** — Crimson Noir on the home screen, glass panels throughout, and every page
  follows your accent theme: Chats, the assistant, settings and the rest.
- **Socials that feel alive** — friends, groups and the shared public room with voice notes,
  badges, and player avatars taken straight from their Minecraft profile on profiles, rows and
  chats alike.
- **Diwali Special** — the announcement page with a live countdown, calendar reminder, share and
  copy actions, and gold animations across the whole page.
- **Honest by design** — branding fields stay owner-locked, errors are shown instead of hidden,
  and the About tab keeps the real credits: a GPL-3.0 fork of PojavLauncher, built by entitybrian.
- **Under the hood** — live update checks, safer chat polling, and dozens of fixes across the
  launcher since 1.0.

## Compatibility notes

Minecraft 26.x support is experimental. The newer animated-cape path and waving integration have
not yet been verified in a real game on every device; animated capes are currently a local-client
effect and are not synchronized to other players. Performance and renderer compatibility depend on
the device and game version. Discord may also use the application icon configured in its Developer
Portal when it cannot show the supplied presence image.

## Downloads

Choose the full APK for an included Java runtime, or a `-noruntime` APK to download runtimes as
needed. Select `arm64-v8a` for 64-bit ARM devices, `armeabi-v7a` for 32-bit ARM devices, or the
universal APK if you need another architecture. Checksums are included in `SHA256SUMS`.

Existing installations can update in place only when the package ID, signing certificate and version
code are compatible. Back up important game data before installing a major update.
